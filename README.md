# NAIJA LIFE

*Your Life. Your Lagos. Your Rules.*

A Nigerian open-world life simulation in the browser, built with React, TypeScript and Three.js (React Three Fiber).
This prototype is one playable Yaba neighbourhood: character creation, a 3D street with day and night, needs, money, food, housing and rent, transport, a smartphone, NPCs with routines, NEPA and more.

```bash
npm install
npm run dev
```

**Controls:** WASD or arrows to walk · Shift to run · Space to jump · E to enter, talk or board · P for phone · I for bag · Esc for menu · drag to turn the camera, scroll to zoom. On phones: joystick, plus buttons for action, run and jump.

Read **GUIDE.md** for how everything works and how to add places, food and NPCs.
